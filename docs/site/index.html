桌面应用 · 非浏览器运行

从扫描件中提取印章与深色字迹

一个跨平台 Python 桌面小工具：把扫描件或照片上的印章、手写签字、深色字迹从背景纸上分离出来，导出为「红白图」（红色 = 保留区域，白色 = 背景），可自选 300 / 600 dpi A4 输出。

本页面为静态图解说明，展示真实界面截图与操作流程；软件需在本地安装或从源码运行，无法在浏览器中直接使用。

下载安装包 从源码运行

要解决什么问题？

纸质文件扫描后，印章、签字与纸张背景混在一起，难以单独取出用于排版或打印回纸质文件。

输入

扫描件或照片上的印章、手写签字、深色字迹，常见格式为 jpg / png / bmp / tiff。

处理

通过灰度亮度范围过滤分离前景与背景；支持全图过滤与套索圈选局部精修，全程实时预览。

输出

红白图（红 = 保留，白 = 背景），可选 300 dpi（2480×3508）或 600 dpi（4960×7016）A4 画布，图像自动居中。

工作原理

基于亮度阈值，而非在线 AI 服务。

核心流程：彩色 → 灰度 → 亮度范围过滤。灰度值落在设定区间内的像素被保留；纸张背景通常较亮（接近 255），印泥偏暗——把最大值拉低即可滤掉背景。

操作流程图解

以下截图为仓库 docs/ 目录中已验证的界面截图，按实际使用顺序排列。

  1. 1

    打开图像

    启动桌面应用后，点击左上角「打开图像 (Ctrl+O)」，支持 jpg / png / bmp / tiff。

  2. 2

    加载文档

    打开图像后，程序将彩色图转为灰度，并在画布中显示。可使用滚轮、快捷键或按钮缩放与平移视图。

  3. 3

    全局亮度过滤

    拖动「🌐 全局亮度过滤」的最小值 / 最大值滑杆：

    • 灰度值落在区间内会被保留（彩色覆盖模式下显示原图内容，其余变黑）
    • 底部状态栏实时显示保留区域占比

    全局过滤只在首次有效：一旦使用套索，全局参数即锁定；重新加载图像可解锁。

  4. 4

    套索圈选，局部精修

    全局过滤后若某些区域仍不干净（例如印章盖在文字上）：

    • 点击「开始套索选择 (L)」，按住鼠标左键圈出要精修的区域
    • 区域出现绿色描边，进入预览状态
    • 拖动「📍 选中区域亮度过滤」滑杆，仅圈内应用新参数
  5. 5

    应用局部阈值

    确认预览效果后，按 Enter 将局部参数应用到选中区域。按 Esc 取消，按 Delete 清除重选。

  6. 6

    检查黑白效果

    将显示模式切换到「纯黑白图」，确认最终保留区域（白色 = 保留）。

  7. 7

    导出红白图

    点击「导出红白图 (Ctrl+S)」：

    • 红色 = 保留区域，白色 = 背景
    • 可选 300 dpi 或 600 dpi 的 A4 画布，图像自动居中
    • 导出后可用 Word 或打印排版

使用说明与限制

以下内容均来自 README 与源码，未作额外承诺。

  • 桌面应用，非浏览器工具：需在 Windows 或 macOS 本地运行，或自行从源码启动；本网站仅为静态说明页。
  • 基于亮度阈值：处理方式为灰度亮度范围过滤，效果取决于原图对比度与拍摄/扫描质量。
  • 全局过滤锁定：首次使用套索后，全局亮度参数会被锁定；需重新加载图像才能再次调整全局设置。
  • 支持格式：打开 jpg / jpeg / png / bmp / tiff / tif；导出为 png 或 jpg。
  • macOS 未签名：首次打开可能提示「无法验证开发者」，可按 README 说明移除隔离属性或右键打开。
  • 项目背景：代码由既有 Windows 可执行文件反编译还原并经人工修复；另修复了 macOS 文件选择对话框的兼容性问题。以 MIT 协议开源。
  • 依赖：opencv-python、numpy、pillow；界面使用 Python 自带的 tkinter。
